# 客户 API 网关

客户入口为 [用户概览](https://cocaapi.com/account/home/)。账号、余额、充值和安全设置保留。网关页面直接导入现有管理后台组件，复用原页面布局、表格、弹窗、图表、聊天界面和 CSS，不维护另一套网关页面设计。原后台功能到客户页面的完整映射见[实施计划](../../docs/superpowers/plans/2026-11-01-customer-gateway.md)

## 原页面复用

| 客户入口 | 直接复用的原组件 |
| --- | --- |
| `/account/home/` | HomePage |
| `/account/keys/` | ApiKeysDashboard、VirtualKeysTable、CreateKey、KeyInfoView |
| `/account/models/` | ModelsAndEndpointsPage、AllModelsTable、ModelInfoView |
| `/account/playground/` | PlaygroundPage、ChatUI |
| `/account/usage/` | UsagePage、UsageOverview、ActivityMetrics |
| `/account/logs/` | LogsPage、RequestLogsTable、LogDetailsDrawer |
| `/account/limits/` | BudgetPanel、BudgetTable，只读本人 API 限额 |
| `/account/docs/` | APIReferenceView |

`CustomerNativePage` 在取得客户 Session 后挂载原组件，使用独立查询缓存。请求适配层把原组件的数据协议转换成客户接口；未支持的管理操作拒绝，并隐藏对应入口。客户页面不读取管理员登录 Cookie，也不继承管理员选定的远程 worker；离开页面后恢复原后台请求配置。原管理员页面继续使用原鉴权和数据接口

模型详情兼容被隐藏的上游字段，不能把缺少字段当作上游未配置。用户只看到本人获准使用的模型名，上游供应商、参数、凭据和未公开价格保持隐藏。缺少价格显示原组件的占位符。密钥累计消费、周期重置、实际速率和最后活动时间来自原生存储，不能用本期消费冒充累计消费

## 权限与数据

客户接口位于 `/account/api/v1/gateway`，只使用客户 HttpOnly 会话。服务端从 Session 取得 user_id，用户不能指定其他用户、团队、上游地址或更高预算。密钥列表只返回本人非团队密钥的白名单字段，操作 ID 加密，不公开原生密钥 hash。新密钥明文仅在创建后显示一次，不写入浏览器存储。创建及删除要求近期身份验证，写操作沿用 Origin、CSRF 和限流

模型授权复用原生校验，支持模型名称、通配符、模型访问组和 `all-proxy-models`。`no-default-models` 始终优先拒绝。目录不公开上游 URL、部署参数或提供商凭据。密钥创建经过原生生成接口，以保留平台的 upperbound 和 policy 校验；生成后再次核对个人归属、llm_api 路由以及空团队、组织、项目、Agent 和对象权限。默认配置注入其他权限时立即通过原生接口撤销，不把密钥交给用户，返回 `personal_key_unavailable`，需要管理员检查默认密钥设置

账号预算按原生预算周期执行，不复制成密钥的一次性终身预算。密钥仍受平台默认密钥限制及原生用户、模型、速率和全局限制。新注册客户继续保持零预算及无默认模型，不能自行抬高额度。钱包与原生 API 预算是两道检查，充值不会自动提高 API 预算。个人 Key 与 Playground 已接入钱包预扣和实际费用结算，余额不足返回 402，计费边界及冻结核对见 [余额文档](WALLET.md)。USDT 网关仍待接入

Playground 只接受本人的个人密钥及当前已授权模型，使用原生推理鉴权与调用链，支持有界多轮文本对话，限制输入长度和输出 Token，不接受任意路由、工具或请求配置。原 ChatUI 在客户模式下不保存密钥、对话或自定义头到浏览器存储。密钥有效期支持秒、分、时、天，默认 30 天且最长 365 天，选择的模型必须是当前授权的子集

日志和用量依据密钥归属关联，不信任请求中可伪造的 user 字段；删除后的密钥通过原生删除档案保留历史。原日期筛选可查询最长 90 天的时间窗口，日期必须带时区，原用量页按浏览器当前时区分组，客户 API 默认按 UTC 分组。日模型统计、成功与失败次数、延迟和 Token 来自真实日志，仅计入模型调用，不返回正文、上游地址或内部元数据。没有提供缓存统计的视图隐藏缓存指标，避免用零值表示未知数据

客户删除路径在原生删除后补充 `evict_and_broadcast`，清除本地认证对象及 Redis，并广播其他 worker。原生删除档案和审计保留。该补充仅在删除成功后执行，使用现有广播的异步 best-effort 机制，不新增撤销存储或更改全站缓存配置

服务器 Caddy 2.6.2 会把 `>Cache-Control` 当作字面头名称，账号静态页面因此缺少预期缓存头。配置已改用显式 `defer`，通过 Caddy 适配后的 JSON 及实际 HTTPS 响应验证账号页面和接口的 `Cache-Control: no-store`、`Referrer-Policy: no-referrer`，无需升级 Caddy
