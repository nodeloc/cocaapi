# 管理后台与用户后台语言切换

管理后台顶部、用户后台顶部及登录注册页提供“中文 / English”选择器，沿用现有 Select 与布局。默认中文，选择记录在非敏感 `coca_locale` cookie 和 `cocaapi.locale` localStorage 中，刷新和后续访问沿用选择，同源标签页同步变化。禁用存储时仍可在当前页面切换

页面切换语言不重建表单，不清空输入。语言只作用于界面文案、可访问名称、选项展示和日期数字格式，美元金额保留原有精度。模型名、供应商名、用户填写的名称、Key 值、角色值、分组 ID、API 参数、代码和模型回复保留原样。服务端返回的原始诊断信息继续显示原文

词库位于 `ui/litellm-dashboard/src/lib/i18n/{zh,en}.json`。English 原文不需要重复写入英文词库，中文原文在英文词库维护对应翻译，缺词回退原文。插值使用 `%{0}` 等占位符，值只插入一次，React 以文本渲染。界面没有运行时翻译请求或 DOM 文本替换

源码级工具 `scripts/localize-ui.mjs` 为静态文案接入翻译。JSX 使用 `LocalizedText`，属性使用 `translateMessage`，静态配置对象通过 WeakMap 保存文案元数据，展示时用 `localizedProperty`。原对象的值、键、序列化及比较不变；接口或用户数据不带元数据，因此即使名称与词库相同也不翻译。表格保留 TanStack 原有列 ID，下拉框只翻译显示标签，提交原选项值

新组件优先直接使用上述接口。纯模块的静态配置可用 `markUiCopy`，克隆用于导航等展示的配置时显式继承来源。组件订阅 `useUiLocale`；展示翻译位于 memo 内时加入语言依赖。不要翻译请求字段、模型标识、React key 或持久化状态

## 构建与发布

在 `ui/litellm-dashboard` 执行 `npm run typecheck`、定向 Vitest、`node --test scripts/localize-ui.test.mjs`、`npm run build` 及 `npm run postbuild`。构建产物为静态 `out/`，无需新增环境变量、OAuth 凭据或数据库迁移

增量镜像使用 `deploy/cocaapi/Dockerfile.i18n`，`COCAAPI_RUNTIME_IMAGE` 指向发布前正在运行的完整镜像，只覆盖 `/app/cocaapi-ui/`，继承原有计费、余额检查、权限与上游配置。发布时先备份配置和数据库，启动 4001 预发布实例验收，再切换主实例。Caddy 切换使用配置验证和服务重启，避免已知热重载卡住问题

可通过恢复此前镜像回退这次界面更新，不涉及数据结构回退
