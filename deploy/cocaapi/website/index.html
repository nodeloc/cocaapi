开始之前

你可能想知道。

如何开始第一次 API 调用？+

注册并登录账号，完成必要的邮箱验证。确认账号已获模型权限与调用额度，并有足够可用余额后，在「API 密钥」创建 Key，再使用上面的接入示例。具体授权范围可在模型目录与调用限额中查看。

已有的 OpenAI SDK 可以使用吗？+

可以。将 SDK 的 base URL 设置为 https://demo.cocaapi.com/v1，使用 CocaAPI 的 API Key，并将模型名称改成你已获授权的名称。支持范围可在账户内的接入文档中查看。

为什么有余额，仍然无法调用？+

余额、模型权限和调用限额会分别检查。请确认已验证邮箱、Key 有效、模型已授权，并且调用限额足够。预扣预计费用高于可用余额或存在待补缴费用时，也会拒绝调用。

支持哪些模型和登录方式？+

模型目录会列出你的账号实际可用的模型。账号与第三方登录方式以登录页当前开放的选项为准。

API Key 应该放在哪里？+

将 Key 保存在服务端环境变量或密钥管理工具中，通过自己的后端调用 API。不要把密钥写入网页源码、公共代码仓库或发给其他人；发现泄露后请立即撤销并重新创建。
