# CocaAPI 开源官网实施计划

**目标：** 根据用户提供的深色 HTML 参考和当前仓库，新增独立开源官网

**实现：** 静态 HTML、CSS 和 JavaScript，放在 `deploy/cocaapi/opensource-website`，复用本地品牌与字体资源。项目介绍明确基于 LiteLLM，部署示例使用现有 Compose 文件，账号和计费扩展链接到仓库文档

**范围：** 首页、功能、部署及调用示例、架构、控制台示意、项目文档、贡献入口、FAQ。使用黑白主体和品牌光晕，不编造版本、统计、价格、社区链接或支付能力

**验证：** 使用浏览器功能测试先验证缺失页面，再实现 SDK 标签与键盘操作、复制反馈、主题持久化和移动导航。检查 320、375、768、1024、1440px、关闭 JavaScript、禁用存储和减弱动画

**交付：** 单独提交和推送新增文件，发布独立预览，保留现有商业站点及其他工作区修改
