# 充值跳转与超时修复计划

**Goal:** 将充值按钮改为“去支付”，创建成功直接进入收银台，过期订单不再提供支付入口

**Architecture:** 单独计算支付链接有效期，易支付取上游链接 expires 参数和本站 30 分钟有效期的较早值。已有金融核对截止时间保持原语义，不用收银台链接的有效期拒绝已经实际支付的充值。列表实时更新过期状态，继续支付前主动查单

**Tech Stack:** 现有 FastAPI 支付服务、React 后台组件和 PostgreSQL 账本

**Spec:** 本轮用户关于自动跳转和 invalid or expired checkout token 的反馈
