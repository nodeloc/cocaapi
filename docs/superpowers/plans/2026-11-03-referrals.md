# 邀请有礼实施计划

**Goal:** 新用户通过邀请注册并验证身份后，邀请双方各获得一次可消费额度，后台配置金额且默认关闭

**Architecture:** 邀请关系仅在创建新账号的事务中绑定，注册时保存活动金额快照。邮箱验证和 OAuth 新账号注册触发幂等发放，两笔余额变动共用事务与现有钱包账本。OAuth 邀请上下文单独建表，不给原 OAuth 表增加会影响旧服务读取的列

**Tech Stack:** FastAPI、Pydantic、PostgreSQL、现有 React 管理和用户后台组件

**Spec:** 用户确认“注册完成并验证身份后双方得额度”“后台可配置，默认关闭”

## 规则

邮箱验证成功或受支持 OAuth 授权注册完成视为身份验证。只有新注册账号能绑定一次邀请，已有账号登录、重复验证及绑定其他 OAuth 不能重新领奖。奖励金额以注册时配置为准，活动关闭时的新注册不补发，既有待验证邀请保留原快照。奖励进入 USD 额度钱包，沿用债务抵扣、余额检查和原调用扣费规则
