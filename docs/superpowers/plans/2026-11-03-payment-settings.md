# 易支付后台配置实施计划

**Goal:** 管理员在现有后台配置易支付网关、商户号和 RSA 密钥，保存后立即用于新支付请求

**Architecture:** 独立单例配置表保存加密密钥和版本号，复用账户认证密钥与完整管理员鉴权。无数据库配置时读取原环境和密钥文件，首次保存后以数据库为准。支付协议、历史订单和账本不变

**Tech Stack:** FastAPI、Pydantic、PostgreSQL、现有 React 后台组件

**Spec:** 当前用户请求“支付设置密钥功能放到后台，支付就叫易支付”

## 约束

保持支付关闭；不回显密钥；留空保留，清除必须停用；普通用户和只读管理员禁止访问；保留现有回调路径和内部 provider 标识；沿用现有界面风格与中英文切换
